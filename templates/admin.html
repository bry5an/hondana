Pipeline

Run a stage on the server. One runs at a time, and while it runs nothing else can save changes. Each run leaves a report and a log under data/logs/.

Dictionaries

The Yomitan dictionaries Hondana for iPhone imports from this server (Jitendex, a monolingual dictionary, pitch and frequency lists). They stay on this server and are never committed or backed up. Uploading a zip with the same file name replaces it, and the app offers the update the next time it refreshes.

Audio sync queue

Japanese books whose audiobook is on this server but that Hondana for iPhone can't follow yet.

Prune audiobooks

The catalog lists every book the account has ever owned, including ones you have no intention of reading. Removing a title hides it from the library and the audiobook pages. No files are deleted — to reclaim disk space, delete the download from its series page first. Pruning is reversible; restore anything below.

Pruned audiobooks

Titles you have removed. Restoring one puts it back in the catalog listing exactly as it was.
